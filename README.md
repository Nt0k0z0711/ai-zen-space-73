# AI Productivity Hub

Create a modern AI productivity dashboard with a clean minimalist design.

Design Requirements:

Use a light gray background (#F8FAFC).

Create a collapsible left sidebar with:

Dashboard

Smart Email Generator

AI Research Assistant

AI Chatbot

Help

Sidebar width: 250px

Active menu item should have a soft blue background (#E0E7FF).

Main Content:

Hero Section

Large rounded rectangle banner.

Gradient background from #5B7CFA to #8B5CF6.

Border radius: 24px.

Padding: 40px.

White text.

Title:

"Work faster with AI"

Subtitle:

"Three focused tools for professionals: write better emails, digest research and get instant answers. No account needed — everything stays in this browser session."

Tool Cards Section

Display 3 cards in a responsive grid.

Card Style:

White background.

Border radius: 20px.

Subtle shadow:

box-shadow: 0 8px 24px rgba(0,0,0,0.08);

Padding: 30px.

Smooth hover animation.

Hover Effect:

Transform translateY(-6px)

Stronger shadow

Transition: 0.3s ease

Cards:

Card 1:

Icon: Mail

Title: Smart Email Generator

Description:

"Draft polished emails with the right tone in seconds."

Button:

"Open →"

Card 2:

Icon: Search

Title: AI Research Assistant

Description:

"Turn topics, articles or links into a clear research brief."

Button:

"Open →"

Card 3:

Icon: Message Square

Title: AI Chatbot

Description:

"Ask questions, brainstorm ideas and plan your work."

Button:

"Open →"

Information Banner

Below cards create a notification panel:

White background.

Rounded corners 16px.

Small shield icon.

Text:

"AI-generated content is intended to assist with productivity and should be reviewed for accuracy before being used in professional or business communications."

Typography:

Font: Inter

Heading: 36px, bold

Card titles: 22px, semibold

Body text: 16px

Spacing:

Use generous whitespace.

Max content width: 1400px.

Gap between cards: 24px.

Animations:

Fade-in on page load.

Card hover effects.

Smooth sidebar transitions.

Responsive Design:

Desktop: 3 cards per row.

Tablet: 2 cards per row.

Mobile: 1 card per row.

Use Tailwind CSS, React, TypeScript and Lucide React icons.

The overall look should feel modern, professional, similar to Notion, Linear, and modern SaaS dashboards.

Style Inspiration:

Soft shadows

Rounded corners (20-24px)

Blue/Purple gradient hero section

Clean enterprise SaaS aesthetic

Minimalistic layout

Plenty of white space

Smooth micro-interactions
